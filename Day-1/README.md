# Day-1: Customer Support AI Assistant

## Project Description
This project develops an AI-powered customer support assistant for Sunrise Bake House using Groq API.

The assistant answers customer questions about bakery services, cake orders, and available options.

## Technologies Used
- Python
- Groq API
- Large Language Model (LLM)

## Features
- Answers customer queries.
- Provides bakery service information.
- Gives cake ordering guidance.
- Generates simple and friendly responses.

## Installation

Install the required packages:

```bash
pip install groq
```

## API Key Setup

Add your `GROQ_API_KEY` in Google Colab Secrets.

## Execution

Run the `task.py` file in Google Colab after configuring your API key.

## Expected Output

The assistant responds to customer questions and provides helpful bakery information.
