# Day-3: LearnPath AI Conversation and Evaluation

## Project Description
This project develops an AI-powered study assistant using LangChain and Groq API. It maintains conversation history, answers student questions, evaluates responses, and demonstrates an AI agent.

## Technologies Used
- Python
- LangChain
- LangChain-Groq
- Groq API
- CSV

## Features
- Maintains conversation history.
- Generates personalized study plans.
- Creates automated test cases.
- Evaluates AI responses using keywords.
- Displays evaluation results.
- Demonstrates an AI agent using LangChain.

## Installation

```bash
pip install -U langchain langchain-groq
```

## API Key Setup
Add your `GROQ_API_KEY` in Google Colab Secrets.

## Execution
1. Open `task.py` in Google Colab.
2. Install the required packages.
3. Configure your Groq API key.
4. Run the code.
5. Check the conversation and evaluation results.

## Expected Output
- AI-generated study suggestions.
- Conversation demonstration.
- CSV evaluation results.
- Agent-generated study timetable.

## Conclusion
This project demonstrates conversation memory, response evaluation, and AI agent development using LangChain and Groq API.
