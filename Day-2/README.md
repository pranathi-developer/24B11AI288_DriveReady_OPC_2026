# Day-2: LearnPath AI Study Assistant

## Project Description
LearnPath AI is an intelligent study assistant developed using Python and the Groq API. It helps students prepare study schedules, understand difficult topics, and manage their study time.

## Technologies Used
- Python
- Groq API
- OpenAI Python SDK
- IPyWidgets
- Generative AI

## Features
- Classifies student requests.
- Extracts student information.
- Creates personalized study suggestions.
- Maintains conversation history.
- Measures execution time.
- Provides an interactive chat interface.

## Installation

```bash
pip install openai ipywidgets
```

## API Key Setup
Add your `GROQ_API_KEY` in Google Colab Secrets.

## Execution
1. Open the task.py file in Google Colab.
2. Configure the API key.
3. Run the code.
4. Enter your study-related questions.

## Expected Output
The assistant identifies student requests and provides useful study guidance through an interactive chat interface.

## Conclusion
This project demonstrates how Generative AI can help students organize their learning activities and improve their study experience.
